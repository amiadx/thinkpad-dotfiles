## basic start
this example will be for artix, but should be easy to apply to anything else.
install paru/yay if you haven't already:

```bash
sudo pacman -S --needed git

git clone https://github.com/amiadx/thinkpad-dotfiles.git
cd thinkpad-dotfiles

# note, please review this package list! don't install stuff you don't need!
paru -S --needed - < packages.txt

stow -t ~ .
```
for any other non-arch based distro, please install everything in packages.txt.

spotify + spicetify + marketplace setup (not required):
```bash
spotify-launcher

# focus to spotify and log in before executing the following...
spicetify config spotify_path "$HOME/.local/share/spotify-launcher/install/usr/share/spotify"
spicetify config custom_apps marketplace

spicetify config current_theme text
spicetify config color_scheme PureBlack

spicetify backup apply
```

## items provided
here are the main items that have provided configs:
- equibop (vesktop with extra plugins)
- fastfetch (neofetch but faster)
- hyprlock (customizable lockscreen)
- mako (notification daemon)
- niri (scrolling window manager)
- rofi (app opener)
- spicetify (spotify customization)
- starship (shell prompt)
- wallpapers (lain wallpaper)
- waybar (status bar)
