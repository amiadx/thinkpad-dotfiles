# thinkpad dotfiles
these are my current dotfiles for my t460

## quick start
this example will be for arch, but should be easy to apply to anything else:
```bash
paru -Syu
paru -S brightnessctl concord-bin fastfetch git gnome-keyring helium-browser-bin hyprlock kitty ly micro niri pavucontroll rofi seahorse soteria-bin spotatui-bin starship stow swaybg swayidle thefuck thunar ttf-jetbrains-mono ttf-jetbrains-mono-nerd waybar xdg-desktop-portal-gnome xdg-desktop-portal-gtk zoxide zsh zsh-autosuggestions zsh-syntax-highlighting

git clone https://github.com/amiadx/thinkpad-dotfiles.git
cd thinkpad-dotfiles

stow .
```
